# 🏋️‍♂️ Golden Gym - Sistema de Gestión de Gimnasio

> Proyecto desarrollado en Java como parte de la **Tecnicatura Universitaria en Programación (UTN)**.

---

## 📌 Descripción

**Golden Gym** es un sistema orientado a objetos diseñado para la gestión de un gimnasio y sus entrenadores. El sistema permite modelar la estructura de instructores, equipos de entrenamiento y la interacción entre el personal del gimnasio y los clientes/socios.

---

## ✨ Características Principales

- 🏋️ **Gestión de Entrenadores:** Registro y control de información sobre entrenadores (`Entrenador.java`).
- 👥 **Personal Trainer y Equipos:** Manejo de entrenamiento personalizado (`PersonalTrainer.java`) y asignación de equipos de trabajo (`EntrenadorEquipo.java`).
- 🏬 **Administración de Gimnasios:** Gestión global de sedes e instalaciones (`Gym.java`, `Gimnasios.java`).
- 🛠️ **Utilitarios y Funcionalidades Auxiliares:** Módulos de soporte para operaciones generales (`Utilitarios.java`).

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java (POO - Programación Orientada a Objetos)
- **IDE:** NetBeans
- **Control de Versiones:** Git & GitHub
